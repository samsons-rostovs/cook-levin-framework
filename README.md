# Cook-Levin Framework

Interactive framework for simulating Turing machines and visualizing the Cook–Levin reduction to SAT.

## Features

- Turing machine simulation
- Execution tracing
- Computation tableau generation
- SAT encoding
- Educational visualization tools

## Project Goals

This project aims to provide an executable and educational implementation of core concepts from computability and complexity theory, focusing on the Cook–Levin theorem and NP-completeness. 

## Background

This project was inspired by a university seminar group project on the Cook–Levin theorem and computational complexity theory at ETH Zürich.

The repository is being independently developed and elaborated as an educational and engineering-focused framework for exploring Turing machine computations, SAT encodings, and NP-completeness.
